### 📲 How to Install on Android

1. Download the **`OwlTrack-v2.apk`** file above directly to your Android device.
2. Open the downloaded file from your browser or **Files** manager.
3. If prompted, tap **Settings** and allow **"Install unknown apps"** for your browser/file manager.
4. Tap **Install** (or **Update** if you already have v1.0.0 installed).
5. Open OwlTrack and start logging!
